# 评论格式模板

## 问题严重级别

- **[Critical]** - 必须修复：安全漏洞、严重 bug、数据丢失风险
- **[Major]** - 建议修复：潜在 bug、性能问题、并发安全问题
- **[Minor]** - 可选修复：代码风格、命名规范、类型溢出风险
- **[Suggestion]** - 优化建议，非必须

## 总结评论模板

```markdown
## Code Review 总结

**整体评价**: ✅ 代码质量良好，可以合并 / ⚠️ 有问题需要修复 / ❌ 存在严重问题

### 变更概述
简要描述本次 MR 的变更内容和目的。

### 亮点
- ✅ 亮点 1
- ✅ 亮点 2

### 发现问题
| 级别 | 位置 | 问题 |
|------|------|------|
| Critical | `file.go:10` | 问题描述 |
| Minor | `file.go:20` | 问题描述 |

详见下方行内评论。

---
🤖 Code Review by Claude
```

## 行内评论模板

```markdown
**[问题级别]** 问题标题

```go
// 问题代码片段

```

**问题描述**：
详细说明问题原因和潜在影响。

**建议**：
1. 建议方案 1
2. 建议方案 2（可选）

```go
// 建议的修改
suggestedCode()
```

🤖 Code Review by Claude
```
