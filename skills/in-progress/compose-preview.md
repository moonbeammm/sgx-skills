Compose Preview
预览 kntr compose 与 android xml ui，直接查看布局、日夜主题和动画效果。通过 Paparazzi 渲染目标代码与最小依赖，无需编译大仓/安装 Apk / 真机或模拟器。
安装：
/plugin marketplace add https://git.bilibili.co/ai-marketplace/client.git
/plugin install compose-preview@client

使用：
在项目会话中说明 预览哪个组件、想看什么效果，比如‘用 compose-preview 预览xx组件，看看长文案和空状态的日夜效果’
